BIRLASHTIRILGAN NODE.JS UY VAZIFALARI

1. Module (qo'shish va ayirish):
   node main.js
   yoki: npm run module

2. fs moduli:
   node fs-task.js
   yoki: npm run fs-task

3. Buffer:
   node buffer-task.js
   yoki: npm run buffer-task

4. Asosiy loyiha:
   node index.js
   yoki: npm start

5. Loyiha papkalari va kerakli boshlang'ich fayllarni yaratish:
   node create-structure.js
   yoki: npm run create-structure

Node.js o'rnatilgan bo'lishi kerak.
Buyruqlarni VS Code terminalida ushbu loyiha papkasi ichida bajaring.
